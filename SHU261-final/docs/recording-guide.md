> 本文件是期末作业《环境声设计》的**录音施工单**。

## 一、先解决"用什么软件录"

### 首选：手机自带「录音机」App

大部分安卓 ROM（MIUI / HyperOS / ColorOS / OriginOS / One UI）自带录音机都支持设置录音格式，路径通常是：

```
录音机 App → 右上角设置（齿轮）→ 录音格式 / 音质 / 编码
   ├─ 有 "WAV / PCM / 无损" 选项  → 选它，采样率选 48000 Hz（没有就 44100）
   └─ 只有 "高 / 中 / 低"（m4a）  → 不要用它录正式素材，换下面的 App
```

**必须要 WAV 的原因**：本机没有可用的 ffmpeg（现存两个副本是裁剪构建，连 PCM 编解码都没编译进去），
`.m4a`（AAC）我无法无损解码。WAV 我能直接按位读入，且是题目要求的交付链路。

### 备选 A：RecForge II（安卓，免费，最推荐）

Google Play 搜 `RecForge II`，设置里：

| 设置项 | 选择 |
| --- | --- |
| Format（格式） | `WAV` |
| Sample rate（采样率） | `48000 Hz` |
| Bit depth（位深） | `16 bit`（Pro 版可 24 bit，16 bit 够用，我后期升位） |
| Channels（声道） | `Mono` 单声道即可（基底立体声我后期做） |
| Auto Gain / AGC（自动增益） | **关闭** |
| Noise Suppression（降噪） | **关闭**（降噪会吃掉房间底噪，没法后期补） |
| Source（输入源） | `Mic`（不要选 Voice Recognition / 通讯模式） |

### 备选 B：Easy Voice Recorder（安卓，免费）

设置 → `Recording format` → `WAV (PCM)`；`Sample rate` → `48 kHz`；关掉 `Auto gain`。

### 备选 C：电脑 + REAPER（本机已装 `D:\r1per`）

只有在你手头有 USB 话筒 / 声卡时才有意义。笔记本自带麦克风音质明显不如手机，
**不推荐**用自带麦录基底素材。若要用：

```
REAPER → Options → Preferences → Device
   Audio system: WASAPI
   Sample rate: 48000，Block size: 512
   Input: 你的话筒
轨道 → 录音（Ctrl+R）→ 录完 File → Render
   Format: WAV，Bit depth: 24 bit PCM，Sample rate: 48000，Channels: Mono
   Normalize/NO normalize → 直接出 WAV
```

### 绝对不要用的方式

- ❌ 微信 / QQ 语音消息、语音通话录屏（重编码 + 强降噪）
- ❌ 蓝牙耳机麦克风（带宽窄、底噪大、带 AEC 回声消除）
- ❌ 任何"AI 音质增强 / 智能降噪 / 美声"开关
- ❌ 手机自带"通话录音"功能

## 二、手机端通用设置（每次开录前逐条检查）

| # | 动作 | 原因 |
| --- | --- | --- |
| 1 | 开**飞行模式** | 避免来电/推送震动被录进去，也避免射频干扰啸叫 |
| 2 | 开**勿扰模式**，关振动 | 同上 |
| 3 | **垫一块毛巾/毛衣**在桌面，手机放上面 | 手机直接放桌面会与桌面共振，低频发闷且有"咚咚"撞击声 |
| 4 | 确认麦克风孔（通常在底部/侧边）**没被手指或保护壳挡住** | 挡住会变成低通+风噪 |
| 5 | 关闭 App 的自动增益、降噪、格式压缩 | 见上 |
| 6 | **每段录音开头留 5 秒安静**（录着不动，不说话） | 这 5 秒是我做噪声底估计/降噪的样本，非常重要 |
| 7 | **每段录音开头拍一次手 + 口报编号**（如"三号，空调"） | 打板对齐 + 我可以据此核对文件名 |
| 8 | 看电平：峰值落在 **-12 dBFS 到 -6 dBFS** | 安卓 App 多半没有电平表，就宁小勿大，**绝不能削波**（削波后无法修复） |

## 三、话筒摆位基本法

```
        声源
          │
          │ 20–40 cm
          ▼
   ┌──────────────┐
   │   手机（麦孔朝向声源）│   ← 手机平放，垫毛巾，麦孔不要贴桌面
   └──────────────┘
        桌面
```

- **近场（10–30 cm）**：单个小物件（键盘、鼠标、杯子、书页）→ 声音结实、细节多。
- **中场（0.5–1.5 m）**：椅子、门、抽屉、房间整体 → 有空间感。
- **远场（>2 m）**：房间底噪、窗外 → 只有远景层用。
- 录**动作类**声音（键盘、门、抽屉）时，**每个动作单独录一次**，动作之间停 2 秒，方便我切分。
- 录**连续声**（风扇、空调、窗外）时，**至少 60 秒**连续录，中间不要有人说话、不要碰桌子。

## 四、素材清单（这是作业要求的"两种声音素材"）

### A 组 —— 基底持续声（Continuous / Ambience）

> 目标产物：一条 **> 30 秒、可无缝循环**的卧室/书房环境底噪。
> 每个 A 项都录 **≥ 60 秒**，宁多勿少。

| 编号 | 内容 | 时长 | 话筒距离 | 关键要求 |
| --- | --- | --- | --- | --- |
| **A1** | 房间安静底噪（Room Tone） | 90 s | 房间中央，1 m | 关窗、关空调、电脑关机，房间内**无人说话、无人走动**；这是最核心的一层 |
| **A2** | 电脑机箱风扇 | 60 s | 30–50 cm，对机箱进/出风口 | 电脑开机正常负载；保持机位不动，录满 60 s |
| **A3** | 空调出风 / 桌面小风扇 | 60 s | 1 m，略偏轴（不要正对风口） | 正对风口会过曝低频；没有空调就录风扇中档 |
| **A4** | 窗外街区底噪 | 60 s | 窗口内侧 30 cm，麦孔朝窗外 | 开窗；尽量选人少时段（深夜/清晨），避免人声和喇叭 |
| **A5** | 房间长时间整体（可选） | 180 s | 房间一侧，1.5 m | 保持"人坐着做事"的状态，让键盘/椅子/翻书自然混入，供剪切时做自然感过渡 |

### B 组 —— 随机间断声（Random / Spot FX）

> 目标产物：**≥ 3 种**、每种 **≥ 3 条** 随机声资产。
> 每个 **take 单独一条文件**，take 之间停 2 秒；每类至少录 **5 take**（我挑 3 条最好的）。

| 编号 | 内容 | 单条时长 | 话筒距离 | 具体录法 |
| --- | --- | --- | --- | --- |
| **B1** | 键盘敲击 | 2–10 s | 15–25 cm | ① 单键重敲 ×5；② 连续打字（真实一段）10 s ×3；③ 空格/回车/退格各 3 次 |
| **B2** | 鼠标 | 2–5 s | 15–20 cm | 左键单击 ×5、右键 ×3、滚轮来回滚 ×3、拿起放下 ×3 |
| **B3** | 椅子 | 3–8 s | 40–60 cm | 转动（带轱辘）×3、前后滑动 ×3、坐下/起身 ×3；木椅再加"吱呀" ×3 |
| **B4** | 房门 | 3–6 s | 60–100 cm | 开门 ×3、关门 ×3、轻关门 ×3、门吸撞击 ×3（注意不要吵到邻居） |
| **B5** | 抽屉 / 柜门 | 2–5 s | 40–60 cm | 拉开 ×3、推回 ×3、钥匙/把手 ×3 |
| **B6** | 纸张书本 | 2–6 s | 20–30 cm | 翻书页 ×5、揉纸 ×3、合上书本 ×3、写字 ×3 |
| **B7** | 手机 | 2–5 s | 20–30 cm | 桌面振动 ×3（放在木桌上）、提示音 ×3、拿起/放下 ×3 |
| **B8** | 桌面小物 | 2–4 s | 20 cm | 水杯放下 ×3、笔掉落 ×3、耳机放下 ×3、台灯开关 ×3 |
| **B9** | 远处人声（可选） | 10–20 s | 隔一堵墙/门 | 合住环境里自然出现的远处说话声，作为"生活感"层；**只录不可辨识内容**，不录他人隐私信息 |

### C 组 —— 加分项（可选，但能明显拉高评分）

| 编号 | 内容 | 时长 | 说明 |
| --- | --- | --- | --- |
| **C1** | 房间脉冲响应 IR | 2 s ×3 | 用**气球爆破**或**拍手**在房间中央录 3 次，可用于后期做真实房间混响（声音设计课很吃这一套） |
| **C2** | 环境细节 | 各 5 s | 拉窗帘、开关灯、拖鞋脚步、倒水 |

**最低可交线**：A1 + A2 + A4（基底三选二即可）+ B1 + B2 + B3（三种随机声）。做到 B1–B8 全部 + C 组就是完整作品。

## 五、合住环境（家里有人）的应对办法

你确认录音环境是"合住/家里有人，会有人声干扰"，这一点直接影响剪辑质量，做法：

1. **抢时间窗**：优先在深夜或清晨录 A1/A2/A3 三条基底——底噪干净程度决定成品上限。
2. **长录多冗余**：基底每条录 90–180 s（清单里已按这个要求），人声一旦出现就继续录，我后期挑干净的 40 s 片段做循环。
3. **人声中断就停 3 秒再继续**——不要紧贴着人声结束就接着录，留出切点。
4. **基底分轨思路**：不同时长的两段干净片段（比如 45 s + 38 s）可以拼成一条不重复感更强的长循环，比单段 30 s 循环耐听得多。
5. **B 组动作声受影响最小**：短促动作声只要那 2–3 秒里没人说话就行，可以随时抢录。
6. **别在录音时开窗又开空调还开着风扇**——每层单独录，混音在后期做，这样我能控制各层比例。

### 命名规则

```

```

`编号_英文短名_序号.wav`。序号 01、02、03……**不用中文、空格和特殊符号**（Wwise 和脚本都好处理）。

### 存放位置

```
E:\dpsk\final-raw\
   ├─ A1_roomtone_01.wav
   ├─ A2_casefan_01.wav
   ├─ ...
   └─ B1_keyboard_typing_03.wav
```

**平铺一个目录就行**，编号前缀已经能区分类别。

### 先交一段试录（重要）

正式开录前，请先录 **1 条 20 秒试录**（随便什么内容，最好是 A1 房间底噪），
命名 `TEST_01.wav` 放到 `E:\dpsk\final-raw\`，我立刻验证：

- 文件能不能解码（是不是真 WAV、采样率、位深、声道数）
- 电平是否合理、有没有削波
- 底噪水平够不够做基底

**验证通过后再录全部**，避免录完一整套才发现格式不对要重来。
