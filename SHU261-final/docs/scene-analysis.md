# 场景分析：卧室 / 书房（电脑桌）

> 本文是期末作业的**第一环节**：确定场景 → 描述场景 → 拆解声音构成 → 明确需要采集哪些素材。
> 后续的录音清单、剪辑、Wwise 集成全部由本文推导而来。

---

## 一、场景设定与文字说明

**场景**：一间学生宿舍/住家卧室里靠墙摆放的电脑桌区域（下称"桌前空间"）。

**空间描述**

- 一个 3 × 4 m 上下的封闭房间，硬装为瓷砖/木地板 + 白墙，房内有一扇朝外的窗、一扇通往走廊的门；
- 靠墙一张 1.2 m 左右的电脑桌，桌上是显示器、键盘、鼠标和随手放的水杯、耳机、书本；
- 桌前一把可转动的办公椅（带脚轮），人坐下后整个身体都在这个"桌前空间"里；
- 房间里有持续运转的电子设备：电脑主机（机箱风扇常年转）、以及季节性使用的空调/桌面小风扇；
- 窗外是一条生活性街道，白天有车流和零星人声，傍晚与深夜明显安静下来。

**为什么选这个场景**

1. **它是"真实可接触"的日常场景**：不需要外景、不受天气和时段限制，可以反复重录、把细节做扎实；
2. **它的声音结构对比强烈**：持续层（设备气流 + 房间底噪）绵密稳定，偶发层（键盘、椅子、鼠标）短促尖锐，
   两类素材在 Wwise 里正好分别用"循环 Sound + Random Container"来承载，最能体现中间件的分层思路；
3. **它的偶发声有天然的"距离语义"**：键盘在 20 cm，椅子在 50 cm，门在 2 m，
   Positioning 与 Attenuation 的设计有真实依据，而不是为了交作业硬凑一个 3D 参数；
4. **它难得地"安静"**：房间底噪低（实测原始底噪约 −55 ~ −60 dBFS），
   于是持续层的每一层纹理（风扇叶片、气流、远处车流）都能被听清，剪辑上的取舍能被检验。

场景平面示意见 [`../assets/fig1-scene-layout.svg`](../assets/fig1-scene-layout.svg)。

## 二、空间里的声源清单（先"听懂"再"录"）

把房间里的发声体按**发声方式**列一遍，而不是按"我想要什么声音"列——
这是避免"想当然地录"的关键：先穷举现实，再做取舍。

| 序号 | 声源 | 发声方式 | 频谱特征 | 时间特征 | 是否进作品 |
| --- | --- | --- | --- | --- | --- |
| S1 | 电脑机箱风扇 | 气流 + 轴承 | 120–500 Hz 为主，含 152/240/380 Hz 等叶片谐波 | **持续**，音高音量基本恒定 | ✅ 基底主层 |
| S2 | 房间底噪（墙、地板、室外漏入） | 全场混响残余 | 全频段，能量低 | **持续** | ✅ 基底底层 |
| S3 | 窗外街道 | 远处车流、人声、偶尔喇叭 | 低频滚降、时间上随机起伏 | 持续 + 偶发 | ⬜ 本版未录（见"取舍说明"） |
| S4 | 键盘 | 键帽撞击 + 弹簧回弹 | 2–8 kHz 瞬态强、低频弱 | **偶发**，0.1 s 级 | ✅ 偶发层 |
| S5 | 椅子（转动 / 滑动 / 坐起） | 脚轮摩擦 + 结构形变 | 100–2 kHz，含摩擦噪声 | **偶发**，0.5–2 s | ✅ 偶发层 |
| S6 | 鼠标点击 / 滚轮 | 微动开关 | 3–10 kHz 极短瞬态 | 偶发，< 50 ms | ⬜ 本版未录 |
| S7 | 房门开关 | 门轴 + 门吸 + 空气压缩 | 宽频，含低频冲击 | 偶发，0.5–1 s | ⬜ 本版未录 |
| S8 | 书页 / 纸张 | 摩擦 | 4–12 kHz 噪声性 | 偶发，0.2–1 s | ⬜ 本版未录 |
| S9 | 水杯 / 笔 / 耳机放下 | 硬物碰撞 | 中高频瞬态 + 桌面共振 | 偶发，< 0.3 s | ⬜ 本版未录 |
| S10 | 手机振动 / 提示音 | 振子 / 扬声器 | 低频嗡 + 窄带音 | 偶发，0.5–2 s | ⬜ 本版未录 |
| S11 | 室内人声（远处、隔墙） | 声带 | 300–3 kHz | 偶发 | ⬜ 未采用（见"取舍说明"） |

## 三、三层声音结构（作品的声音设计框架）

```
┌──────────────────────────────────────────────────────────┐
│ 第 3 层  人声层（Living Layer）        ← 可选，本版未采用  │
│          远处说话、走廊人声，提供"有人气"的现场感         │
├──────────────────────────────────────────────────────────┤
│ 第 2 层  偶发层（Spot / One-shot）     ← Random Container  │
│          键盘 8 条、椅子 4 条；短促、随机、带距离语义     │
├──────────────────────────────────────────────────────────┤
│ 第 1 层  持续层（Continuous Ambience） ← 循环 Sound SFX    │
│          机箱风扇气流 + 房间底噪；60.64 s 无缝循环         │
└──────────────────────────────────────────────────────────┘
         ▲ 越往下越"垫底"、越往上越"抓耳"
```

分层结构图见 [`../assets/fig2-sound-layers.svg`](../assets/fig2-sound-layers.svg)。

**为什么必须分两层（而不是录一条"房间环境声"了事）**

| | 持续层 | 偶发层 |
| --- | --- | --- |
| 听感作用 | 提供"这个空间是活的"的**底**，是存在感来源 | 提供"这里有人在做事情"的**信息**，是叙事来源 |
| 时间结构 | 无始无终，必须无缝 | 有明确起止，必须能被随机触发 |
| 中间件去向 | 循环 Sound SFX（`IsLoopingEnabled`） | Random Container（`RandomOrSequence=Random`） |
| 若混在一起 | 循环点会暴露"这段在重复" | 每次循环听到完全一样的事件序列 → 立刻假 |

这条推理直接决定了 Wwise 里的结构，也是本作品"环境声设计"与"随便录点环境音"的区别所在。

## 四、素材需求清单（由第二章推导，含完成状态）

> 要求来源：题目规定"至少两种声音素材：一种是基底的、持续不断的声音；另一种是间断出现的、持续较短的声音"。
> 下表按此要求扩展成**可执行的采集清单**。

| 编号 | 层级 | 内容 | 录制要求 | 话筒距离 | 状态 |
| --- | --- | --- | --- | --- | --- |
| A1 | 持续 | 房间安静底噪 | ≥ 90 s，关窗关空调，无人走动 | 1 m 居中 | ✅ 已录（作参考层） |
| A2 | 持续 | 电脑机箱风扇 | **≥ 60 s 连续**，机位不动 | 30–50 cm 对风口 | ✅ 已录 61.64 s → 基底 |
| A3 | 持续 | 空调 / 桌面风扇 | ≥ 60 s，偏轴避免风口过曝 | 1 m | ⬜ 未录（本版以 A2 单层定稿） |
| A4 | 持续 | 窗外街区底噪 | ≥ 60 s，窗口内侧 | 30 cm 朝窗外 | ⬜ 未录 |
| B1 | 偶发 | 键盘敲击 | 一次录一段连续敲击即可，后期切分 | 15–25 cm | ✅ 已录 32.28 s → 8 条资产 |
| B2 | 偶发 | 鼠标点击 / 滚轮 | 单次动作间停 2 s | 15–20 cm | ⬜ 未录 |
| B3 | 偶发 | 椅子转动 / 滑动 / 坐起 | 一次录一串动作 | 40–60 cm | ✅ 已录 18.88 s → 4 条资产 |
| B4 | 偶发 | 房门开关 | 开/关各 3 次 | 60–100 cm | ⬜ 未录 |
| B5 | 偶发 | 抽屉 / 柜门 | 开合各 3 次 | 40–60 cm | ⬜ 未录 |
| B6 | 偶发 | 书页 / 纸张 | 翻页 5 次、合书 3 次 | 20–30 cm | ⬜ 未录 |
| B7 | 偶发 | 手机振动 / 提示音 | 桌面振动 3 次 | 20–30 cm | ⬜ 未录 |
| B8 | 偶发 | 桌面小物（杯 / 笔 / 耳机 / 台灯） | 各 3 次 | 20 cm | ⬜ 未录 |
| C1 | 附加 | 房间脉冲响应（拍手 / 气球） | 各 3 次 | 房间中央 | ⬜ 未录 |

**本版交付采用**（已满足题目全部硬性要求）：

- 持续层：**A2（机箱风扇）** → 60.64 s 无缝循环基底
- 偶发层：**B1（键盘）8 条 + B3（椅子）4 条** → 共 12 条随机声资产，2 个类别

## 五、设计目标与听感取向

1. **"安静的在场感"**：基底不追求"有气氛"，而追求"没意识到但一旦抽掉就觉得空"——
   这是环境声设计里最难做对的部分：基底过强会盖住点声，过弱则空间不成立。
   因此基底 RMS 定在 **−23 dBFS**，点声峰值定在 **−3 dBFS**，留出约 20 dB 的动态差。
2. **偶发层要"能听出距离"**：键盘（近）比椅子（远）更亮、更干；配合 Wwise 的
   3D Position + 25 m 衰减，让同一条点声在不同距离下有不同的高频损失与音量。
3. **不做"电影化"处理**：不加混响、不加压缩、不做音效化的夸张。
   这是一段**生活声**，可信度优先于戏剧性。
4. **循环不可闻**：基底必须做到单段 60 s、等功率接缝、响度漂移 < 2 dB。

## 六、取舍说明（为什么本版只做了 2 类偶发声）

作业硬性要求是"随机声资产 ≥ 3 个"。本版用 12 条、2 个类别达成，
并且刻意把素材做**深**而不是做**宽**：

- 键盘 8 条是**同一个物理动作的 8 个真实变体**（不同键位、不同力度、单键 vs 连打），
  这正是 Random Container 存在的理由——用变体消除重复感，而不是靠不同类别凑数；
- 椅子 4 条覆盖转动 / 滑动 / 坐起三种动作形态，时长 1.44–2.00 s，正好落在"偶发但不瞬时"的区间；
- 未做的鼠标、门、纸张、水杯等（S6–S10）在第二章已列清，属于同一条采集清单的后续批次，
  不影响本版结构的完整性。

同理，人声层（S11）本版不采用：宿舍/合住环境中录到的人声无法取得清晰授权，
而环境声作品里人声会立刻把听者的注意力从"空间"拉到"内容"上，与本节第 3 条的听感取向冲突。
