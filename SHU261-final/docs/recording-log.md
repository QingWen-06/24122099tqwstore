### 2.2 录制条件备注

- **A2-a → A2-b 的重录原因**：第一次只录了 30.64 s，做 1 s 循环交叉淡化后成品只有 29.6 s，
  不满足"大于 30 秒"；且电平从 −46 dBFS 一路掉到 −51 dBFS（录制时手机或被录对象有移动）。
  第二次改为**一条 61.64 s 连续录音、手机全程不动**，漂移降到 1.8 dB，一次到位。
- **为什么重录而不是靠后期补**：30.6 s 的素材若要凑够 30 s 以上，只能缩短交叉淡化或拼接两遍，
  前者会暴露循环点、后者会产生 30 s 周期性重复——两者都是"技术能过、听感不过"。重录是唯一正解。
- **B1 / B3 的录制思路**：不追求"一次录一个动作"，而是**连续录一串真实动作**，
  后期用 `split_onsets.py` 自动切分。这样做的好处是动作之间是自然的演奏状态（力度、节奏都在变），
  切出来的变体更像真人操作，而不是"摆拍式"的单次敲击。
- **电平原状**：B1 与 B3 中有大量事件峰值恰好落在 −3.0 dBFS，
  这是手机录音链路内部的限幅/AGC 天花板（实测**削波采样数为 0**，未真正削波）。
  由于点声本来就要做峰值归一化，这一现象不影响成品，但记录在此以备核查。

## 三、处理链路（每一步的参数）

### 3.1 基底持续声（`AMB_Bedroom_Base_Loop.wav`）

```
A2-b (61.64 s, 48k/24bit/stereo)
  │
  ├─ 1. 去直流偏移                       → 实测直流 −0.00000
  ├─ 2. 二阶 Butterworth 高通 40 Hz       → 去除低频隆隆声与桌面共振
  ├─ 3. 重采样                           → 源即 48 kHz，无需转换（保零处理）
  ├─ 4. 保留原生立体声                    → 左右声道相关系数 0.30，保留空间差异
  ├─ 5. 段内 RMS 对齐到 −26 dBFS
  ├─ 6. 长时响度漂移压平 ★               → 0.25 s 窗短时 RMS / 中位电平为目标 /
  │                                        修正曲线 2 s 平滑 / 逐样本线性插值 / 限幅 ±8 dB
  │                                        实测漂移 6.4 dB → 1.8 dB
  ├─ 7. 无缝循环化 ★                     → 尾部 1.0 s 等功率（sin/cos）叠到头部 1.0 s，
  │                                        再裁掉尾部 1.0 s：61.64 s → 60.64 s
  ├─ 8. RMS 归一化到 −23 dBFS + 峰值天花板 −3 dBFS（只做线性缩放，不压限）
  │                                        实测施加 +3.0 dB，成品峰值 −8.2 dBFS
  └─ 9. 导出 48 kHz / 24 bit / stereo WAV
```

### 3.2 随机间断声（`KEY_*` / `CHR_*`）

```
B1 (32.28 s) / B3 (18.88 s)
  │
  ├─ 1. 冲击事件检测 ★                  → 5 ms 窗包络 / 噪声底取 20% 分位数 /
  │                                        阈值 = 噪声底 + 10 dB（键盘）或 +8 dB（椅子）/
  │                                        最短间隔合并 30 ms（键盘）或 250 ms（椅子）/
  │                                        最短长度过滤 15 ms
  │                                        实测：键盘 113 个事件、椅子 11 个事件
  ├─ 2. 逐事件裁切                       → 前留 10 ms、后留 60 ms 尾音；单条上限 2.0 s
  ├─ 3. 去直流 + 二阶高通 40 Hz
  ├─ 4. 声道处理                         → 源为立体声则保留（真双麦），单声道则做 12 ms 微延迟伪立体声
  ├─ 5. 淡入 2 ms / 淡出 min(30 ms, 时长/3)  → 消除切点爆音
  ├─ 6. 峰值归一化到 −3.0 dBFS
  └─ 7. 导出 48 kHz / 24 bit / stereo WAV
```

★ = 本作品的关键处理，理由见 [`../README.md`](../README.md) 第四节。

### 3.3 资产筛选原则

自动切分只是"给候选"，最终交付的 12 条是**挑选结果**：

- 键盘：113 个候选中挑 5 条**单键**（时长 0.11–0.20 s、峰值 −3.0 ~ −3.2 dBFS、
  取自录音中不同时间位置以获得不同键位音色）+ 3 条**连打**（0.54 / 0.60 / 0.88 s，用于稀疏时的"忙碌感"）；
- 椅子：11 个候选中挑 4 条，覆盖不同动作形态与不同电平（−3.1 / −6.4 / −7.0 / −16.6 dBFS），
  其中电平差异被保留——它本身就是"动作幅度不同"的真实信息，Random Container 会自然利用这一点。
